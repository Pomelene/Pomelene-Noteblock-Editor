# 0.5.7：全背景演化声纹

按用户要求扩大开始页背景覆盖与形变、配色变化幅度。三组参数每 9 秒连续过渡；线性插值调整尺度和驻波模式，正弦缓动改变配色与扭曲，低频正弦推动旋转与光带。全屏原创 WebGL 干涉场与粒子叠加，左侧稳定玻璃面板保留文件入口。

渲染核心独立于 Electron；shader 长边上限 1280，沿用 30Hz 动画上限及暂停、减少动态、宿主不活动停止和编辑器进入时释放。Canvas 波纹和 CSS 为兼容回退。不改变音乐、音频或文件协议。

新增 3 项插值与连续性测试、3 项真实浏览器渲染测试，验证四象限覆盖及随时间变化、Canvas 回退与暂停状态的上下文恢复。独立审查发现上下文恢复不重绘的边界问题；回归测试先得到亮度 0 的失败，再通过保留最后时间并立即静态重绘修复。复审无后续可操作问题。

最终构建、测试、实际 EXE 检查、两阶段截图与归档校验记录于交付目录 verification。

最终验证：TypeScript（含 unused locals）通过，41 个测试文件共 326 项测试通过；真实 0.5.7 EXE 的基础 20 项、和弦与独立窗口 8 项、开始页 12 项、连接开屏 4 项共 44 项检查通过。22 个构建文件及说明匹配包内内容。main/preload 构建哈希与 0.5.6 相同；两张真实时间截图确认配色与形态演化。
