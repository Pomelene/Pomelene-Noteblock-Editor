# 0.4.0 智能 Pattern 整理 Beta 验收

验证日期：2026-10-18。环境：Windows 11 x64、Node 24.19.0、Electron 44.8.0、150% DPI。本轮增加可选 NBS 整理，保留 0.3.0 发布和旧工程。没有新增运行时依赖。

## 实现与使用

打开 NBS 后显示导入预览，“智能 Pattern 整理（Beta）”默认选中，也可关闭或取消。预览显示原曲信息、整理前后数量和建议分组；复选框在详细报告之前，小窗口仍可看到选择和固定操作栏。原生菜单、工具栏与 Ctrl+O 共用导入流程，预览只属于发起窗口。

整理按原始图层名称与同步发声等证据分组，在 1/2/3/4/6/8 小节候选间选择切句；相同分组内只有长度、音符和图层参数完全相同时才能共享源 Pattern。保留绝对 tick、重复击打次数、音高、音色、力度、声像、微调、图层设置及原曲结束位置。SONG 使用原始尾音窗口，单独 Pattern 试听使用自身长度。手动修改引用长度/偏移或源 Pattern 长度后采用普通裁剪语义。

完整工程保存 `nbs-structure-1` 报告和原始布局备份，重开不重新分析。“帮助 → 智能整理报告…”查看结果；“编辑 → 恢复原始导入布局…”会替换当前音符与编排，界面明确提示，恢复可撤销。取消导入不会替换工程或清掉未保存修改。

研究来源和首版参数的推理过程见 [研究说明](smart-pattern-research.md)。算法模块可独立替换，参数集中管理，不联网、不下载模型。

## 真实语料的校验含义

`scripts/analyze-nbs.cjs <folder>` 只读歌曲并输出统计，不打包歌曲本体。最大输入为 35,361 音符。10 首均满足：

- 整理前后，包含非发声图层在内的原始音符多重集合与全部表现/图层参数一致。
- 音频事件的时间、增益、声像、调音、可播放窗口及曲终点一致。此项比较调度参数；缺失自定义资源时使用占位数据仅供纯数学事件计划，不代表实际解码或主观试听结果。
- 整理后可编码 NBS 并重读；原始工程和整理工程各自经过同一导出/重读路径后，再比较事件与图层属性，全部一致。该对比排除既有导出格式限制的影响，不承诺 NBS 字节完全相同。

例如 The Third Sanctuary：18 组、698 个源 Pattern、1134 个引用，436 个引用复用源。完整分析和两次导出检查在本机本次运行约 0.9 秒。Megalovania 则产生 59 组、391 个 Pattern。这些结果说明复杂曲目仍可能过度碎片化，尚无人工标注集证明分组/切点达到音乐学意义上的正确率。

## 修复和限制

独立审查发现主窗口关闭时只取消自身预览，会遗漏编辑窗口持有的事务；现改为取消全部待决导入，再进行未保存保护。另一处是主动缩短源 Pattern 后仍可能保留导入尾音扩展；现清除该源所有引用的扩展，并支持撤销。两处都有实际复现与回归。

算法预算：8192 小节、2048 lane、64 组、768 Pattern、9000 引用、32 MiB 备份；超限回退原布局并解释，不丢数据。当前切点沿原点小节网格，弱起、跨小节主题、同音色交织声部和人工名称不可靠时仍有误分可能。近似/移调变奏各自保留，不会自动合并；没有自动识别主歌/副歌或生成伴奏。

NBS 自身没有 Pattern 结构；请保存 `.nbproject` 保留整理结果和备份。NBS v0–5 读、v5 写，v6 仍不支持。其它未完成功能继续见 README。所有机器可重复运行的记录、实际截图与文件哈希见交付目录 `verification` 和 `SHA256SUMS.txt`。
