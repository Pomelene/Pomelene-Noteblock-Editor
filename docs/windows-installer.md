# Windows 安装与卸载说明

安装版与免安装版使用相同的 0.5.7 编辑器。安装包采用 electron-builder 的 NSIS 向导，内含完整程序与 Electron 运行环境；目标为 Windows x64，无需安装 Node.js，安装时不必联网下载程序。

## 双击 Setup 后发生什么

1. 向导默认选择当前用户安装。默认目录为 `%LOCALAPPDATA%\Programs\Pomelene Noteblock Editor`；也可选择专用的同名文件夹。为所有用户安装时 Windows 会要求相应权限。
2. NSIS 在 Windows 临时目录准备安装器组件，把 EXE 内嵌的 7z 程序包先展开到临时目录，再复制到目标文件夹。主程序、DLL、语言文件、`resources/app.asar`、说明文档都来自同一个离线包。`app.asar` 是应用资源容器，不是需要你另外解压的文件。安装过程中临时目录和最终目录会同时占用空间，建议预留约 1 GB 可用空间；安装结束后临时目录由安装框架清理。
3. 写入本应用的安装位置及 Windows“已安装的应用”登记，创建开始菜单／桌面快捷方式，并放入 `Uninstall Pomelene Noteblock Editor.exe`。不会添加开机启动项、后台服务或接管 `.nbs` 默认打开方式。完成后不自动启动编辑器。
4. 以后运行的是安装目录内的编辑器，无需每次重新展开整个安装包。本项目没有自动更新器，安装完成后会删除框架默认留在 AppData 中的额外 Setup 缓存副本；你下载的安装包自身可另行保存用于重装。

不要把歌曲、工程或自定义采样存进程序目录；它们适合放在“文档”或你自己的素材目录。当前卸载逻辑会保留额外文件，但与程序文件同名覆盖的数据仍属于程序文件，不能保证保留。

## 卸载

使用 Windows 设置中的“应用 → 已安装的应用 → Pomelene Noteblock Editor → 卸载”，或运行安装目录里的 `Uninstall Pomelene Noteblock Editor.exe`。卸载程序属于这次安装，不能拿来卸载其他路径的免安装目录。

卸载按构建时记录的程序文件清单操作，并移除自身、快捷方式及本应用安装登记。目录只在为空时删除，不递归清空整个程序文件夹。外部歌曲、工程、采样和 AppData 用户数据默认保留；如果安装目录中有额外用户文件，目录会因此保留。不要给卸载器传入 `--delete-app-data`，除非明确希望删除应用的用户数据。

## 保护与实际边界

- 安装目标必须是独立的产品文件夹；未经识别的非空目录、磁盘根目录及目录联接会被拒绝。
- 安装／卸载发现编辑器进程时拒绝继续，要求先保存、退出，不强制杀进程。
- 删除前检查安装路径和清单文件涉及的目录联接／符号链接；不能借此指向外部目录删除文件。
- 先把已安装的程序文件移动到同一磁盘的临时目录。遇到占用导致移动失败时，尝试把已经移动的文件放回，再报告失败；用户文件不参与这个暂存过程。
- 这不等于断电、磁盘损坏或恶意本机程序并发篡改下的完整事务保证。请正常退出编辑器后升级，并保留重要工程备份。
- 目前没有发行者代码签名证书，Windows 可能显示“未知发布者”或信誉提示。安装测试不能替代发行者签名，也不能承诺所有杀毒软件均不误报。无需关闭杀毒软件或修改系统安全策略。

按用户要求不执行 SHA-256 校验、不为本次安装包生成 SHA-256 清单。部署核对采用文件内容直接比较，生命周期验证结果在交付目录的安装器验收记录中。

官方打包选项说明：[electron-builder NSIS](https://www.electron.build/docs/nsis/)。本工程保留标准安装框架，在 `resources/installer.nsh` 和构建钩子中加入上述保护。
