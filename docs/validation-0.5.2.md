# Pomelene Noteblock Editor 0.5.2 验证记录

2026-10-19，Windows x64。工程容器保持 v2；NBS 格式与现有控制事件协议保持兼容。

## 本次功能

- 正式 Pattern 编辑器的“和弦生成器”替换此前基础和弦菜单。共用当前落点、落笔音色、力度和起始图层，支持大调／自然小调的七个调内和弦，以及九类自定义和弦、转位、附加音、低音、开放排列、上下行分解和自动前进。
- 面板打开时左键选择落点，钢琴卷帘同时选根音，图层视图选起始图层；关闭后恢复普通绘制。生成的是普通音符，可继续编辑、保存工程和导出 NBS。
- 默认追加并自动跳过占用／锁定图层。显式替换仅影响生成时刻的当前音色，保留其他音色、锁定音符及时间不同的音符。一条主进程命令提交整组，整组撤销／重做。
- 和弦试听使用现有采样和音色映射，按同一 AudioContext 时钟调度；关闭、换文档或取消待解码试听不会迟到发声，取消试听不停止整曲播放。
- 右键连续擦除共用实际绘制矩形，修正整小节吸附时空白误删及低缩放边缘命中；快速指针线段插值，锁定保护，松开提交一次历史，Escape／失焦取消。多鼠标键同时按下时也在起始按钮松开时提交。
- 内部与原生编辑窗口均可使用面板，窄布局改为画布上、面板下；面板可独立滚动。拍号分母参与落点显示。

## 审查与范围

独立审查已尝试，但审查任务因服务端 429／用量限制未能返回结果。本次由实现者自行检查核心边界、异步取消、文件保存及指针生命周期，并对发现的鼠标组合键与拍号显示问题执行先失败后通过的回归测试。这不能视为完成了独立审查。

原型中的私有 JSON 导出和本地缓存没有进入正式工程。开放排列、附加音及转位沿用已确认原型的规则；暂不增加智能配和弦、声部进行优化或效果器。
