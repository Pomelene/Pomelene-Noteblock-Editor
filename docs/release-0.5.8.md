# Pomelene Noteblock Editor 0.5.8

## NBS v5 / v6 导出

- 导出时可选择 NBS v6（推荐）、NBS v5（兼容旧版）或取消。
- v6 支持四种原生铜号：铜号、斑驳铜号、锈蚀铜号、氧化铜号。
- Pattern 编辑窗口的音色栏增加“添加铜号”，一次添加四种内置音色，可撤销；已有自定义乐器编号保持不变。
- 四种真实音频随应用提供，打开原生 v6 铜号歌曲无需另选采样目录。
- v6 导出同步转换原版音色、自定义乐器及控制事件编号，最多容纳 236 个自定义定义。
- v5 将铜号保留为自定义乐器。通过“文件 → 导出乐器采样包”生成对应资源，与歌曲一起分发。
- 修改了 NBS 调音或按键设置的铜号保留为自定义乐器，避免丢失这些设置；导出时会提示分发采样包。

## 安装与升级

运行 `PomeleneNoteblockEditor-0.5.8-Setup-x64.exe`，使用与原安装相同的安装范围和位置。安装器沿用原应用标识，更新卸载登记和快捷方式，保留额外用户文件与 AppData 设置。全用户安装需要 Windows 管理员权限。

升级前请先保存工程并退出编辑器；安装器不会强制结束正在运行的应用。完整流程见 [安装与卸载说明](windows-installer.md)。

## 格式与资源

工程继续使用 v2 `.nbproject`，保持已有自定义乐器的内部编号，不把旧工程的乐器 16–19 误认为铜号。源文件中的原生铜号身份单独保存，导出时再生成 v5 / v6 对应编号。

格式依据：[OpenNBS NBS 规范](https://noteblock.studio/nbs)。四种铜号采样来源见 [资源记录](copper-sources.json)。音频资源属于 Minecraft，其权利归相应权利人所有；没有使用合成音或其他乐器冒充铜号。
