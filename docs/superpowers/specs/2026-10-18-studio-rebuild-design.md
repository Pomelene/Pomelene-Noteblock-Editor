# NoteBlock Editor 0.3 新工作区

用户明确要求参考 NBS 官方说明后继续开发，并建议另起炉灶。本轮授权覆盖重建，不再停在通用交互提问或 HTML 演示。新代码独立放在 desktop-next，旧 desktop 和已有交付保留。技术栈仍是 Electron / React / TypeScript。

## 必须满足

- Pattern 与采样均为一等源对象，编排中放置独立引用；引用有自己的长度、偏移和静音。默认拖长补空白、缩短裁播放窗口，不循环、不变速、不删源。显式创建独立副本。
- 多编辑视图按 view id 管理，可同时打开不同 Pattern 或采样；四边四角缩放、最大化还原、最小化、置前、原生弹出。不能按源对象全局去重而限制显式新增视图。
- 编辑画布右键删除，列表右键有对象菜单。菜单位置、禁用、外部关闭和 Esc 正常；不强加 Ctrl+右键。
- 播放／暂停与终止分开，暂停保留位置，终止一次归零并把竖线带回起点。主子窗避免双重播放，声音以音频时钟调度。
- 主工作区以 FL 的菜单、传输、Picker、Playlist、浮动编辑器组织，图层与钢琴两种编辑方式保留 NBS 触发事件语义。音色选择在 Pattern 编辑上下文出现。
- 真实可见控件接通命令、历史或文件操作，不提供假按钮。错误不能卸载整个应用；滚动不捕获失效的 React 事件。
- 工程文件独立保存完整状态；NBS v0–v5 读取、v5 导出使用经过验证的底层格式模块，经新对象适配器接入。采样引用不能直接伪装为 NBS 音符导出。v6 未建立兼容性时明确拒绝。
- 自定义乐器从 NBS 定义导入，并支持上游打包 ZIP 的采样文件；自动按相对路径关联。ZIP 中仅音频时无法凭空推断乐器定义，应保留原定义、按路径关联或创建可编辑采样。
- `.nbproject` 新 schema 2，同时能迁移旧 schema 工程。音色资源携带可迁移数据，用户不需重选每个采样。
- 不做滤波、混响、专业混音、切分工具和滑音；MIDI 智能转换与 GarageBand 风格半自动丰富留在后续清单，不以假入口交付。

## 参考理解

NBS 官方格式 https://noteblock.studio/nbs ，官方教程 https://noteblock.world/help/creating-song ，FL Playlist / Piano roll / Channel Rack 手册。图层的名字、音量、声像、锁定是实际数据；NBS 音符是触发而非持续音。音量乘层音量，声像应对照文档与上游播放实现，不能沿用未经验证的简单相加。自定义基准音高必须参与速率计算。源码 pack_instruments 将采样相对路径打包到 ZIP，定义另在 NBS 中。

## 具体设计选择

使用低饱和石墨灰工作区、温暖橙色传输指示、薄荷绿／蓝紫乐段色，系统中文字体，12px 左右高密度标签，避免原版零散小字和大块说明性装饰。浏览器并列列出 Pattern 与采样；轨道头有静音、独奏和菜单。编辑器内部把工具、乐器行、画布、力度和属性区分层，不把全部参数塞成多排表单。初始示例可用于体验，新建为空。

接口以 src/shared/model.ts 为准。主进程负责工程权威状态、校验、历史、文件与资源访问；渲染器负责独立视图和局部交互。播放引擎通过受限信号协调所有窗口。

## 本轮验收

真实 Electron 中实际鼠标拖动滚动条、四边角缩放、最大化还原、列表菜单、双编辑实例、音符与乐段编辑、长度裁剪、暂停继续终止、真实 16 采样解码、导入自定义包、保存重开、NBS 往返。密集内容与 1080p/高 DPI 截图评审。源码包和运行包分开，最终 ZIP 解压后再次验收。472 条总表为持续开发清单，不宣称本轮全部实现。
