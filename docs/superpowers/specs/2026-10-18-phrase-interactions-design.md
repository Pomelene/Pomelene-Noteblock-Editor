# 片段采样与编排交互设计

依据用户本轮直接要求实施：连续放置、片段尾部补零/截断、改善节拍吸附，并将“采样”定义为只读的可复用音符片段，支持根据采样创建 Pattern。沿用 Electron/React/TypeScript 桌面工程和已确认的 FL 式窗口/列表右键/画布删除规则。开发者按既有授权直接完成具体实现，不另开确认轮次。

## 概念和兼容

Pattern 是可编辑音符源；片段采样是包含音符和图层设置的只读快照，两者都能在 Playlist 中重复引用、移动、复制、静音和裁剪。双击片段采样打开只读预览；创建独立 Pattern 后编辑，不会影响原采样。浏览器默认并列显示 Pattern/片段采样，音频文件和乐器单音资源移入明确命名的音频资源区域，继续兼容旧工程，不能把旧 OGG 凭空转成音符。

我的实现选择：增加 `phrases?: PhraseSample[]`，其中 PhraseSample 与 Pattern 具有相同的音符/图层数据；原有 `samples` 继续表示历史音频资源。Clip/Source 新增 kind `phrase`。新工程有空片段库，旧工程可缺失；工程 schema 2 不变。所有音符编辑命令只接收 patterns 中的对象。片段只允许重命名/改色/删除；复制成 Pattern 使用全新 ID。播放和 NBS 导出按音符处理 phrase，保持图层/乐器/表现属性。

创建入口：Pattern 对象菜单“保存为片段采样”；Playlist 选择片段的菜单“保存选区为片段采样”；文件和片段库“导入 NBS 片段采样”。导入片段不会替换工程或触发整曲整理，并合并所需自定义乐器/音频。片段菜单“根据采样创建 Pattern”；编排引用菜单支持创建 Pattern 并替换该引用。创建/转换/删除、文件导入均为可撤销原子事务，保留其它对象。

## 绘制与编排

官方 Playlist/Piano roll 将绘制 P 与笔刷 B 分开。保留单次绘制及拖动；新增真正的左键按住拖动连续放置。Playlist 的笔刷按源片段长度接续，跨轨道也可画；补齐快速拖动经过的格子，回扫不重复，避免大量重叠。钢琴卷帘按吸附格连续加触发事件，能上下画和弦；NBS 音符无独立持续时长，不伪造长音工具。右键按住拖过多个对象连续删除。一个手势形成一次历史，松开提交，Esc/失去指针/换工程取消预览。Ctrl 临时框选、Shift 拖动复制已存在对象；空白处 Shift 临时笔刷。

尾部拖动必须有明确命中区、横向调整光标和实时长度/补白反馈，菜单小角标不能抢占左右裁剪边缘。调整单个引用，即使已有多选也不能意外改源或同源其它引用。拉长补静音、缩短裁播放窗口，源数据保留，不自动循环或拉伸。采样引用遵循同样规则。拖动过程只预览，提交一次并支持撤销。

合理补齐相关局部菜单和快捷键：绘制/笔刷/选择/删除，编排静音与滑移、复制剪切粘贴、接续复制、全选/取消选择、缩放适应内容、保存为片段采样、创建独立 Pattern。仅展示实际实现的动作，不补切片/滑音/效果器占位。

## 吸附

共用一个有磁铁图标、可见“吸附”标签的选择器。采用稳定字符串值而非小数 value；分组显示“关闭”“自动网格”“按拍值”“三连音”“小节”。按四分音符拍计：1 拍=4 内部 tick，1/2 拍=2，1/4 拍=1，1/8 拍=0.5，1/3 拍三连=4/3；1 小节跟随拍号。选项文字同时显示音符值或三连音含义，移除目前把 1/3 tick 笼统叫三连音的歧义。自动网格随缩放调整，显示的网格与实际吸附一致；关闭及 Alt 临时绕过时仍遵守内部精度。绘制按格首放置，拖动以相对位移吸附，保留原始离格偏移。键盘微移使用当前步长；不因改变吸附而修改既有数据。

## 验证和发布

先用失败测试固定采样不可变/独立转换、播放导出、原始音频兼容、吸附/三连音与拍号、快速笔刷/回扫/取消/一次撤销、单引用裁剪边缘。再运行全部类型、单元和真实 Electron 流程。实际查看常规/紧凑窗口、只读采样、工具栏和拖动反馈；保留智能整理回归。新版本 0.5.0，Windows 运行 ZIP 与源码 ZIP 分开，旧发布目录保留。
