# 0.6.1 修复设计与实施记录

用户要求：消除播放位置数字位数变化造成的晃动；以本机 notebot 歌曲库验证更鲁棒的 NBS 读取；PAT 目标跟随编排选择和活动 Pattern 编辑器。

- 位置组件保留拍内 tick×100 语义，TICK 固定三位，BAR 预留七字符、BEAT 两字符，字体与栅格固定；真实浏览器测试跨位数、长小节号和拍号切换的字段/标签/邻接控件位置。
- 按 systematic-debugging 先扫描实际失败和字节结构，再以独立合成文件做失败回归。旧版 112 首只能导入 67 首。仅接受经典格式可确认的全零尾部；缺少图层设置按真实音符最高层补全；无自定义定义的经典扩展原版 ID 按原版读取；异常力度明确提示规范化。
- 依据官方规范增加 v6 读取，保留本工程自定义音色 ID 起点 16；新铜号按具名自定义资源转换，需要真实音频。未知尾部和截断音符不自动猜测修复。
- 单 Pattern 上限 500,000 音符，工程总数 1,000,000，文件字节等限制继续保留。迁移、全选边界和批量复制使用逐项计算，选择查询使用集合，避免参数栈溢出和二次扫描。
- 鼠标选择引用、来源列表和编辑器/窗口栏激活统一设置来源；PAT 正在播放时用现有音频 generation 机制切换，SONG 保持整曲。播放状态通知不再反向覆盖用户当前选择。
- 解析兼容提示加入导入预览，只显示一次；片段导入没有预览时通过原有结果提示显示。

按 dispatching-parallel-agents 分开调查计数器和解析器，主线程完成整合及桌面测试。部分工作线程中断后由主线程继续完成。新用例均先观察失败再实现，最终独立审查未发现具体 P1/P2。
