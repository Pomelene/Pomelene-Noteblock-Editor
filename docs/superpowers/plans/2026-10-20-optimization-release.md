# 0.5.9 性能与体积整理

**Goal:** 保留美术、音乐和交互结果，清理无用路径，降低运行与分发成本；更新 GitHub 主分支、最新 Release 和 F 盘已安装应用。

**Architecture:** 延续 Electron/React/TypeScript 和 StudioAPI 边界。工程状态由 Session 独占，每次状态变更只编码一次，快照仍深克隆隔离；播放指针与静态编辑内容分层；波形摘要按解码音频对象复用。构建启用压缩，打包只保留中英文运行时语言文件，不删除 GPU、音频、许可证或美术资源。
