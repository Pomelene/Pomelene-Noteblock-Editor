# 核心路径求简

目标：保持 v2 工程、NBS v5/v6、音色映射、智能整理和编辑交互的现有结果，减少重复查找、分配与自制机制。当前任务直接执行，不扩展功能或更换运行环境。

## 范围与约束

- 播放计划：在一次构建内索引资源，单音预听继续使用简单直接的接口；不缓存跨工程可变状态。
- NBS 导出：索引乐器、采样、Pattern/片段；同一来源的图层映射只计算一次，保留冲突分层、原图层编号和警告顺序。
- 智能整理：用完整字符串 Map 直接识别重复片段；移除重复克隆和候选间重复边界计算，不改变分组/分段决策及完整性验证。
- 资源包导出：统一内置/外部音频的路径冲突检查，大小写冲突仍按原规则拒绝不同数据。
- 编辑器：消除拖动绘制中的嵌套线性查找，复用资源与选区索引；不改变图层顺序、命中顺序和手势提交时机。
- 不改动序列化格式、generation、跨窗口播放所有权、原子写入和安装注册；不打包/发布本轮安装程序。

## 验证步骤

1. 修改前记录固定混合工程的导出完整字节、警告、播放事件及智能整理布局；同一 fixture 用于可重复的本地性能对照。
2. 分模块修改并执行已有编解码、映射、时间线、智能整理、文件与浏览器交互回归。
3. 类型检查、全量测试、生产构建和实际 Electron 烟雾测试。
4. 写入实际性能结果与剩余问题，不用代码行数替代可维护性，不宣称所有算法都已最优。
