# Windows installer implementation plan

**Goal:** Deliver an offline Windows x64 NSIS setup wizard for the verified 0.5.7 app, including a usable uninstaller and plain Chinese explanation.
**Architecture:** Reuse electron-builder 26.15.3. Default per-user assisted install, editable dedicated product directory, optional shortcuts, no automatic launch or file associations. Preserve app data. Generate a compile-time owned-file deletion macro from the actual packaged tree; never recursively remove the installation directory. Original runtime and source archive remain intact until verification.
**Tech stack:** Existing Electron + electron-builder + NSIS; Node build hooks, PowerShell installation lifecycle verification.
**Scope:** Packaging only, version remains 0.5.7. No updater/service/startup task, no new UI features. No paid signing identity is available; report unsigned status honestly. Per user instruction, do not run SHA-256 checks or generate hash manifests. Compare deployed bytes directly where needed.

- [x] Add and observe failing tests for owned-file list generation, escaping, traversal/duplicate path refusal and symlink refusal. Implement build hook and scoped deletion macro.
- [x] Configure assisted NSIS, Chinese/English wizard, offline embedded archive, retained data, stable appId, install directory validation, running-process refusal and forced CRC verification.
- [x] Build setup. Verify installer metadata/signature status and embedded payload by actual installation and direct byte comparison.
- [x] On this Windows machine, refuse to test if a real installation is registered. Install into a dedicated Unicode/space path, verify all deployed bytes, registry and shortcuts; run the actual installed EXE smoke. Test same-version reinstall and user file retention; test running-app refusal and unsafe target rejection. Uninstall through the generated executable, verify app removal, shortcut/registration removal, preserved external and install-directory user files and app data. Clean test-created artifacts only.
- [x] Request independent review. Resolve important findings, preserve installer + separate source ZIP + verification; avoid keeping a second unpacked app. Commit and back up source on main and installer-specific tag.

Review focus: path traversal or NSIS injection; junctions; unknown nonempty targets; unsaved work during reinstall/uninstall; user projects surviving cleanup; scope of real-machine registry/shortcut tests. Installation is not claimed atomic across power loss, and unsigned status is not Microsoft certification.

Execution evidence: 330 tests / 42 files pass, TypeScript passes. Real NSIS setup installed 77 packaged files byte-for-byte in a Unicode/space path, passed 12 lifecycle checks and 12 installed-EXE start/file/window checks. Refused unsafe/nonempty targets, destination/internal junctions and running editor; locked-resource reinstall restored all bytes; read-only program file and staging tree removed on uninstall; external/internal user files and real Electron userData retained. Unsigned installer. Interactive wizard click-through, cross-version upgrade and power-loss transaction guarantees are outside the observed tests. Source backup/archive and cleanup completion recorded in release verification.
