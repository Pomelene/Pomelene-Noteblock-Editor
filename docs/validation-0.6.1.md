45 次初始失败包括：38 个经典文件末尾全零填充、2 个文件头少报图层、2 个超过旧音符上限、1 个异常力度文件、1 个未声明经典扩展音色、1 个 v6 文件。另有 104,914 音符歌曲同时超旧上限，初次先因力度异常失败。

解析器只接受可确认的经典全零尾部；补全少报的图层设置，不改变音符位置；经典文件没有自定义定义但使用 10–15 号乐器时按已知扩展原版音色读取，并提示。未知非零尾部、截断音符、未知版本仍拒绝，当前工程保留。

《Black Knife (Deltarune CH3+4 OST)》含 55 个力度 125 的音符，超出官方 0–100 范围。本版明确提示规范为 100，保留全部音符。这是有提示的兼容转换，不宣称原始非法力度逐字节不变。

官方 v6 布局与 v4/v5 相同，原版音色增至 20。本版正确重映射自定义音色起点；用到的新铜号保留为具名自定义资源，导出仍为 v5，需要对应音频。未使用的铜号不会增加无用资源，缺失音频不使用其他音色冒充。未承诺所有外部自定义采样都存在或可试听。

单 Pattern 上限增至 500,000 音符，工程总数 1,000,000；NBS 文件仍受 32 MiB 及 tick、图层、字符串等限制。迁移和选区边界使用逐项计算，选择查询使用集合，避免大曲的参数栈溢出和二次扫描。

最大曲《Note Block Megacollab》265,495 音符。在源码候选与最终 ZIP 实际解压 EXE 中均完成：打开、全选、适应选区、保存到测试目录、重开并核对音符数量和末尾数据。112 个原始文件的 SHA-256 前后相同。

## 位置与播放目标

- TICK 始终三位，保留原有拍内 tick×100 语义。数字栏、分隔符、标签与邻接控件位置固定；七字符小节槽覆盖工程最大位置。
- 真实浏览器在 1400/1000 宽度下核对 009→099→100→310、999→1000 小节、最大位置以及 4/4、6/8、2/2；几何位置一致。
- 点击编排引用、来源列表、激活 Pattern 编辑器或底部窗口栏会设置 PAT 目标。PAT 播放中切换来源立即切换试听，异步解码使用既有 generation 取消旧请求；暂停后选择另一来源，恢复时播放新来源。SONG 继续整曲播放。
- 音频状态广播不再把来源选择反复改回旧播放对象。PAT 按钮提示当前目标名称。
- 兼容处理在导入预览展示一次，避免导入后重复阻塞弹窗；没有预览的片段导入仍通过结果提示展示。
