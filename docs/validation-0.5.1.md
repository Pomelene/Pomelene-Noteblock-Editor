## 明确范围

- `.nbproject` 只接受带 `PNE-PROJECT v2` 前缀的新格式，不支持旧工程迁移。NBS 外部歌曲兼容不因此移除。
- 视觉控制只保留、展示并重新导出，不执行彩虹或背景效果；Show Save Popup 不产生文件写入。
- 全局事件目前是只读信息；带事件歌曲通过整曲打开，不能直接导入成片段。Pattern 预听使用初始 BPM。
- 指定层范围停止器遇到会改变目标身份的碰撞层分配时，NBS 导出明确报错；完整工程仍能保存。NBS v5 的时间和编号边界继续执行。
- 批量对照验证的是数据保留和整理前后播放计划一致，不等同于逐首人工听审，亦不承诺任意第三方非标准扩展。

格式契约和具体实现行为见 [工程 v2 与 NBS 控制事件](project-v2.md)。
