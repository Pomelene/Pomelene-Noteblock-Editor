# Pomelene Noteblock Editor 0.5.9

2026-10-21 · 性能与体积整理。现有图标、音频和视觉设计保持原样，工程仍采用 v2，继续支持 NBS v5/v6 与四种铜号。

## 本轮调整

- 播放与 NBS 导出在一次操作中建立资源索引，重复引用复用图层映射；NBS 编码采用连续缓冲区，减少小对象分配。
- 智能 Pattern 整理直接使用完整签名去重，移除额外哈希分桶、重复边界分析和无效输入的重复克隆；精确音乐内容校验与原布局回退保留。
- 工程状态变更时更新序列化结果，读取快照不再重复编码整曲；深克隆隔离、未保存判断、原子事务和撤销重做保持原语义。
- 编排和音符窗口将播放指针单独绘制，指针移动不重画音乐内容。波形摘要按已解码音频复用，更换音频后自动更新。
- 清理生产中无引用的旧吸附/坐标算法，统一采样包路径冲突处理，并减少批量编辑与绘制中的嵌套查找。
- 生产 JS/CSS 压缩；Windows 发行版只携带简体中文、繁体中文和英文运行时语言包。GPU/音频运行库与许可证保留，未更换运行环境或删减音乐功能。

## 体积与性能

| 项目 | 0.5.8 | 0.5.9 |
| --- | ---: | ---: |
| 前端 JS | 约 891 KB | 约 389 KB |
| Windows x64 安装包 | 100,716,245 字节 | 92,966,562 字节 |
| 应用文件目录 | 约 387.6 MB | 约 338.1 MB |

16,384 音符的固定合成工程上，第二阶段快照读取的七次中位耗时由 19.82 ms 降至 12.96 ms。测量用于比较重复工作，实际歌曲与机器的收益不同。首阶段的播放/导出对照见[核心求简记录](core-simplification-2026-10-20.md)。

## 验证

- 全套 47 个测试文件、355 项测试通过，包含真实浏览器中的缩放、行高、手势、播放指针及音色焦点检查。
- 本地真实曲库 112 首 NBS：112 首解码、导入、导出成功，112 首音乐内容往返一致；原始歌曲未修改。
- 打包版验证四种铜号真实音频解码、NBS v5/v6 与采样 ZIP 导出；15 项窗口/快捷键验证及启动等待、失败重试检查通过。
- 包内容审计确认 21 项公共图标/音频资源逐字节相同，成品不含开发依赖、测试、源码映射；不执行 SHA256 检验。

## 安装与更新

运行 `PomeleneNoteblockEditor-0.5.9-Setup-x64.exe`，沿用既有安装目录及安装范围即可。更新通过正常安装/卸载流程移除旧运行文件，维护 Windows 应用登记、快捷方式和卸载程序。全用户安装会显示 Windows 管理员确认。

安装程序不强制结束编辑器进程；请保存并退出后更新。用户工程、歌曲、额外文件及 AppData 设置保留。界面仍以中文为主，未提供发行者代码签名。

源码包与安装包分开。GitHub 历史 Release 和历史源码保留；本地仅保留当前安装版本与新版安装器，临时解包程序在验收后清理。
