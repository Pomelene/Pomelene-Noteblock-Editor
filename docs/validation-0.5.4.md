# Pomelene Noteblock Editor 0.5.4：Quiet Aurora

2026-10-19，Windows x64。用户提供 DESIGN.md、DESIGN1.md、DESIGN2.md，要求在视觉减法基础上综合 Organic 2.0、Glassmorphism 与 Aurora UI 的优点，尝试视觉权重较低的创新，并加入暂不展开详细设计的纯色开屏。

## 实现范围

- 烟绿暗色、顶部两处低饱和光色、活动窗口一像素薄荷／青蓝／淡紫边缘。光色不进入音乐画布，不使用空闲时循环的背景动画。
- 烟玻璃主要用于标题栏和短暂菜单，提供不支持模糊时的实体底色；没有全画布滤镜或新增图形库。
- 选中音色标签和主要和弦按钮采用轻微不对称圆角，和弦预览以细竖线组织。继续保留上一版紧凑排列、简短文字与明确选中状态。
- 仅实际播放时出现轻微呼吸状态线；减少动态效果关闭装饰动效，高对比度模式提供系统选中色。
- HTML 首帧、React 开屏与原生窗口使用相同纯色背景。开屏显示名称和真实加载状态，首个权威快照到达立即进入工作区，没有模拟进度或最短展示时间。
- 初始化失败显示原因并可直接重试宿主连接。连接可取消，卸载后的延迟结果不再更新视图，初次请求失败后仍能接受宿主广播。

未修改音乐模型、Canvas 音符绘制或命中几何、文件格式及音频调度；main 仅同步原生背景色，preload 无改动。工程容器仍为 v2，当前 Electron 宿主保持不变。无新增运行依赖、网络字体或在线素材。

## 验证

新连接生命周期与开屏行为有 9 项针对性测试；原有回归继续执行。`scripts/boot-smoke.cjs` 在真实 Electron 中临时控制快照 IPC，检查等待、就绪、失败及重试，不在产品中加入延迟或测试后门。
