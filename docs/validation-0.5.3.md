# Pomelene Noteblock Editor 0.5.3：视觉减法

2026-10-19，Windows x64。用户要求：保持暗色，只强调必要信息，去除无意义文字、色块和间隙，减少渐变与粗糙阴影；本轮不增加视觉特效。

## 调整

- 控件、编辑网格、浏览器、窗口与对话框统一为中性灰阶。保留音符／来源颜色、活动工具、播放指针、锁定／静音／错误状态及键盘焦点。
- 去掉装饰性背景渐变和内凹阴影。浮动窗口与菜单只保留一层轻阴影，用来区分重叠层级。采样波形的重复时间网格保留，它是定位参照。
- 音色标签连排、无独立卡片边框；去掉彩色圆点、零数量和重复“当前”徽标。选中音色仍有底色和下划线，键盘选择与其他音色虚化保持。
- 去掉 PL/P/S 窗口徽章、对象顺序编号、重复的来源类型、READY/NOTES、空闲时常驻的快捷键长提示及无意义的轨道说明。
- 顶部使用“整曲／当前片段”“速度”“拍号”“小节／拍／刻度”，保留 BPM 单位与稳定的数字栏宽；精简品牌文字和装饰工程图标。
- 和弦预览取消独立卡片底框，减小标题与间距；详细说明放入可展开的“使用说明”。替换操作保留明确名称与悬停说明，运行错误及放置结果仍显示。
- 减少空采样列表中的说明与边框，保留导入、创建采样和打开所选对象的入口。完整帮助仍可通过 F1／帮助菜单查看。

## 验证边界

`src/shared`、`src/main`、`src/preload` 无源代码变化。音乐模型、指针命中尺寸、文件格式、播放调度、撤销及窗口能力保持现有实现。工程容器仍为 v2。

使用既有 302 项自动测试及真实桌面脚本进行回归，不为这次可逆的样式变化增加只检查 CSS 实现细节的测试。两项既有断言同步了已删除的 PL 徽标和移入悬停提示的原始 tick 文本；保留对窗口聚焦、缩放和自动前进的行为验证。

最终测试报告、打包文件比较、截图与校验和保存在交付目录的 `verification` 和 `SHA256SUMS.txt`。重点检查：整曲编排、Pattern／和弦面板、重叠窗口、右键菜单、密集音符与独立窄窗口。

独立审查结果及最终检查记录于实施计划的执行记录中；不可将审查任务启动视为审查完成。
