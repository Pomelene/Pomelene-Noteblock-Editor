# 0.3.0 桌面重构验收

本版在 `desktop-next` 独立建立 Electron/React/TypeScript 工程，保留旧版 `desktop`。472 项总表仍作为后续开发清单，不把本轮核心验收等同于全部需求完成。

## 已运行的验证

环境：Windows 11，Node 24.19.0，Electron 44.8.0，150% DPI。

- 严格 TypeScript 类型检查，以及 `--noUnusedLocals` 通过。
- Vitest：10 个文件、60 项测试通过，覆盖事务/撤销、裁剪、文件写入失败、并发保存、损坏/取消导入、旧工程迁移、NBS、音频、ZIP、窗口几何和组件、快照顺序。
- 真实 Electron：20 组端到端流程通过。系统对话框仅替换路径选择，实际 IPC、磁盘 IO、采样解码、鼠标/键盘、窗口都使用发布实现。
- 已实际查看 Playlist、Pattern 最大化、采样真实波形、1000×650 内容区密集工程截图。
- 独立审查已完成；指出的异步采样放置跨工程问题已修复并新增回归。

## 修复的代表性细节

- 片段右边缘按拖动的相对位移吸附，避免点中边缘就少一格。
- 暂停保留 AudioContext 时钟位置，停止取消已调度声音并一次归零。
- 切换工程时拒绝旧代际编辑；迟到的旧快照不能把 UI 回滚。
- 关闭持有播放的原生窗口后释放跨窗口拥有者，避免剩余窗口卡在播放状态。
- 保存完整工程不会中止当前播放；NBS 导入不作为 Ctrl+S 原工程写回目标。
- 真实波形从音频解码获得，采样乐段长度由实际音频时长计算。

## 兼容性与范围

NBS v0–v5 读取，v5 导出；v6 明确拒绝。小数 tick、直接音频引用、复杂拍号、非标准音域和只在工程播放中生效的预听设置，导出时给出对应格式提示。完整 `.nbproject` 保留内部对象和内嵌采样。NBS 图层锁定的预听行为依据官方教程（锁定也静音）；导出保留锁定元数据。

自定义音频 ZIP 不包含乐器定义，定义由 NBS 提供；按相对路径自动关联后可随工程保存，并再次导出采样包。尚未实现 MIDI 智能转换、鼓点素材库、自动丰富听感。未验证 macOS/Linux 安装包。物理音箱音质与不同声卡延迟需要用户设备的听感反馈，本轮自动测试验证的是实际音频解码、采样来源与调度语义。


依赖安装配置依据 pnpm 11 官方说明：https://pnpm.io/blog/releases/11.0 ，已允许 Electron / esbuild 的安装脚本，避免新机器缺少 Electron runtime。普通 pnpm typecheck 命令已实际通过。
