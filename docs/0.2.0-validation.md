# 0.2.0 修正与验收

本轮依据用户对整小节放置限制、无效交互及缺少文件读写的反馈实施。

- 移除 Playlist 放置 / 拖动整小节取整；提供实际吸附和缩放。
- 修正共享状态自动将 Pattern 长度取整到 16 ticks 的问题，短 Pattern 保留精确长度。
- 将音符吸附、缩放、名称、长度、音色应用、力度柱、选区属性接入真实命令；多图层 / 长曲采用可见区域画布。
- 接入版本化工程 JSON、NBS v0–5 读取及 v5 导出；保留完整音符属性和附加元数据，旧音色编号映射正确。
- 原子写入、未保存提示、保存取消 / 失败保护、工程切换代次和旧子窗销毁。
- 审查修正：保存路径不再在对话框之后改写扩展名；导入数据必须先通过可保存性验证，超限导入不会替换当前工程；状态提交也验证可保存性。
- 文件格式由实际内容识别，用户自选扩展名不会影响重开；图层 / 琴键列横向滚动时固定，最小化恢复保留子窗口状态。

验证覆盖：共享编辑命令、精确长度、历史、剪贴板、文件失败与取消、NBS 各版本、旧自定义音色映射、速度/拍号转换、超限导入、实际原子替换失败。

真实 Electron 验收脚本 `scripts/smoke.cjs` 通过界面执行编排、编辑、保存、导出、重开及整个进程退出 / 重启。测试仅在 OS 文件选择边界注入路径，文件按钮、preload、主进程和磁盘读写使用正式代码；生产程序不含测试专用路径 IPC。

本机另外读取十首现有 NBS 并导出 / 重读，包含 84 图层及 35,361 音符实例。桌面验收对 35,361 音符的实例逐个核对 tick、图层、音高、音色、力度、声像和微调。

最终结果位于本机 `test-results/smoke-packaged.json`；源码包不包含测试生成的歌曲或用户原始素材。

最终验证：6 个测试文件、57 项单元测试和 TypeScript 检查通过；从 Windows ZIP 完整解压后运行 EXE，10 组桌面验收通过，渲染错误为零。运行包检查不包含 src、tests、node_modules 或 Git 目录；源码包另外生成。
