# Pomelene Noteblock Editor 0.5.7

面向 Windows x64 的音符盒音乐编辑器，提供离线安装包、卸载程序和独立源码归档。

## 编辑与文件

- Pattern 与只读片段采样可重复编排，支持拖动、框选、复制、剪切、粘贴和撤销重做。
- 钢琴卷帘与 NBS 图层编辑，和弦生成器、连续放置及右键拖动擦除。
- 可调整行高与时间缩放，支持编辑子窗口弹出、最大化、组合与停靠。
- 音色聚焦、原版音色试听、自定义乐器与替换映射。
- NBS v0–6 读取、v5 导出，以及带版本标签的 v2 `.nbproject` 工程。
- 导入时可选“智能 Pattern 整理（Beta）”，识别重复乐句并保留原始导入备份。
- 全背景实时声纹开始页，提供打开歌曲、打开工程和新建工程入口。

## 安装目录修复

- 选择安装父目录后自动创建 `Pomelene Noteblock Editor` 子文件夹，父目录可以已有其他文件。
- 修复尚未选择目录就报错的问题，以及尚不存在的目标目录被误判为无效路径的问题。
- 保留对无关产品目录、目录联接及符号链接的检查。
- 安装程序附带卸载程序；卸载保留额外用户文件和 AppData 设置。

## 下载与安装

- `PomeleneNoteblockEditor-0.5.7-Setup-x64.exe`：Windows x64 安装包，内含运行环境，无需另装 Node.js。
- `PomeleneNoteblockEditor-0.5.7-source.zip`：对应发布提交的独立源码，不含依赖、构建输出或应用 EXE。

运行安装包后选择安装位置。以后可通过 Windows“已安装的应用”或安装目录中的卸载程序移除应用。详细过程见 [安装与卸载说明](windows-installer.md)。
