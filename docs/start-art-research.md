# 开屏影像：简单规则产生复杂动态

用户首先选择了克拉尼声纹与粒子聚合，随后补充《小丑牌》是“简单代码产生复杂效果”的灵感。本项目采用同样重视规则组合的思路，视觉保持音符盒编辑器自己的方向。

## 研究来源与判断

| 方向 | 核心规则／视觉 | 项目判断 | 一手资料 |
|---|---|---|---|
| 克拉尼声纹 | 驻波模式的节点集合，粒子向节点聚合，形成具有对称性的几何结构 | 已按用户选择实现一版程序化节点场。音乐关联明确，可用少数模式持续变化 | [Chladni Patterns Generator 作者仓库](https://github.com/hilbertcube/Chladni-Patterns-Generator) |
| 噪声流场／坐标扭曲 | 分层噪声叠加，再扭曲采样坐标，得到云纹与流动纹理 | 后续可用于玻璃背后的缓慢光场；不必等同于普通双色渐变 | [The Book of Shaders 第 13 章](https://thebookofshaders.com/13/) |
| Gray–Scott 反应扩散 | 两种浓度在网格中反应、扩散，产生细胞／珊瑚样结构 | 个性强，需维护二维状态与多次迭代；本轮暂不采用 | [Karl Sims 原作者教程](https://www.karlsims.com/rd.html) |

检索到的 [Azkun/balatroShader](https://github.com/Azkun/balatroShader) 明确是社区重现，不能当作官方开发说明。其文档展示了中心坐标、旋转、三角函数、多次变换和调色参数如何组合成动态背景；这是可参考的算法组织思路。本项目未导入该仓库代码、游戏 shader 或游戏美术。

[LÖVE 官方 Shader 文档](https://love2d.org/wiki/Shader) 与 [入门教程](https://love2d.org/wiki/Tutorial%3AIntroduction_to_Shaders) 也说明了逐像素函数可用于形变、反光及后处理。当前开屏只需几千个粒子，采用现有 Canvas 2D 即可完成，不新增渲染框架或 GPU 运行要求。

## 本版实现

使用原创的简化节点场：

`f(x,y) = sin(nπx) sin(mπy) - sin(mπx) sin(nπy)`

以解析梯度引导粒子降低 `f²`，并加入阻尼；两组整数模式 `(3,5)` 与 `(4,7)` 缓慢混合。细小的视角变化和三组透明色提供层次。它是受驻波启发的程序化影像，不声称物理精确模拟真实振动板与砂粒，也不把模式参数当作当前歌曲的实际频率。

2300 个粒子、最多约 30 次绘制／秒、DPR 上限 1.5。页面隐藏、文件流程进行中或用户暂停时停止 RAF；返回后从同一状态继续。开启减少动态效果时静态绘制，进入编辑器后卸载 Canvas 与监听器。没有视频资源、在线素材或启动音效。
