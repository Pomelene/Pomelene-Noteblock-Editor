# 工程 v2 与 NBS 控制事件

本次优先扩展 `.nbs` 兼容性。应用版本为 0.5.1；工程文件格式独立命名为 **v2**，后缀仍是 `.nbproject`。旧版 JSON 工程按用户要求不再导入，外部 NBS 文件不受影响。

## 文件结构

| 位置 |    长度 | 内容                                                                                  |
| ---- | ------: | ------------------------------------------------------------------------------------- |
| 0    | 15 字节 | ASCII `PNE-PROJECT v2`，随后 LF 换行                                                  |
| 15   |  4 字节 | UTF-8 JSON 数据区长度，无符号小端整数                                                 |
| 19   |  4 字节 | 数据区 CRC32，无符号小端整数                                                          |
| 23   |    可变 | 完整工程 JSON，包括嵌入音频、音色映射、Pattern、片段采样、编排及 NBS 元信息和控制事件 |

总长度上限 96 MiB。读取时先检查版本、数据长度和 CRC，再以严格 UTF-8 解码、解析 JSON 并验证数据类型、资源引用、数量及数值边界。截断、追加字节、校验失败、未来版本和旧工程均被拒绝，当前工程保持不变。数据区保留未知的安全扩展字段；内部 `schema: 2` 是模型版本，与文件容器版本分别管理。

CRC 用于发现意外损坏，不提供加密或来源认证。保存沿用同目录临时文件、刷新和原子替换流程；不覆盖输入的 `.nbs`。嵌入音频继续使用已有的 data URL，无需额外文件夹或新的运行依赖。当前未加入压缩或资源去重，因此大曲及带音频的工程仍可能较大。

## NBS 兼容行为

- 读取 Classic 及 v1–v6；按文件头的原版音色数解释自定义编号，导出为 v5。v6 铜号资源继续作为具名自定义乐器保留。
- 按自定义乐器的准确协议名识别 Tempo Changer、Sound Stopper、Toggle Rainbow、Toggle Background Accent、Show Save Popup 及 Change Color to #…。
- 控制事件与普通音符分开保存为工程级 `nbsEvents`，保留原始位置、层、编号及参数字节。智能 Pattern 整理不会重复、移动或删除这些事件。
- Tempo Changer 影响整曲的音频时钟、跳转、暂停恢复与循环；Pattern／片段预听使用工程初始 BPM。无效的零速度事件保留但不改变速度。
- Sound Stopper 按原始层身份截断此前触发的声音；同一 tick 新触发的音符保留。全停止与指定范围分别处理。
- 视觉事件保留并可在资源面板及自定义音色窗口查看，目前不执行视觉效果。Show Save Popup 绝不会触发磁盘保存。
- 控制定义不作为音频采样，不要求查找其音频，也不允许映射成普通乐器。后续导入资源会避开其编号。
- 来源层状态 1 是编辑锁定，2 是独奏。锁定不等于静音。
- 未识别的自定义乐器仍保留名称、资源引用和音符，不凭关键词猜测行为。普通音符超限力度、声像的修正会明确提示；功能事件使用完整参数字节。

整曲事件不随单个片段移动，因此带控制事件的 NBS 应通过“打开工程 / NBS”导入。直接导入为只读片段会被拒绝并提示原因；仅导入乐器定义不会把来源歌曲的全局事件应用到当前工程。

v5 导出的时间、层数和乐器编号受 NBS 格式限制。普通重叠音符通常分配碰撞层；如果该移动会改变指定范围 Sound Stopper 的含义，导出会报错，避免生成听感不同的文件。完整内容仍可保存为 v2 工程。

## 本轮范围

MIDI、NoteBot 文本、MCSP／MCSP2、NBSTool JSON、音符 CSV／JSON 和 MuseScore 已有调研记录，按用户最新优先级留待后续。Minecraft 建筑结构不视作可直接还原的音乐文件。
