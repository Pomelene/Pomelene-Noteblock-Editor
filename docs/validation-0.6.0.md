# 0.6.0 快捷键与自由工作区验收

环境：Windows 11 x64、Node 24.19.0、Electron 44.8.0、150% DPI。沿用 Electron / React / TypeScript 与 schema 2 工程，无新增运行时依赖。

## 本轮交付

| 类别 | 实际行为 |
|---|---|
| 快捷键 | 56 组绑定、52 个操作；文件、撤销、播放、工具、选区、剪贴板、移动、八度、定位、缩放、吸附、音色与窗口命令按上下文分派，F1 可搜索 |
| 输入保护 | 文字输入保留剪贴板和撤销；文件快捷键可以先提交输入再保存。菜单、对话框不操作后台；按钮焦点的 Enter/Space 保持原生激活 |
| Playlist | 独立工作区子窗口，移动、八边缩放、最大化/还原、最小化、关闭后恢复、平铺、层叠、真实系统窗口弹出与停靠 |
| 多窗口 | 来源可开多个实例；切回编排保留其他窗口，Ctrl+Tab 双向切换。桌面窗口共享工程、撤销和音频状态；停靠时接管播放位置 |
| 音色聚焦 | 当前音色、音符计数和音色按钮更加显眼；其他音色音符与力度条使用 22% 不透明度，选区保持清晰，可显示全部 |
| 紧凑窗口 | 320×220 子窗口对应约 320×188 内容高度时，切换紧凑音色栏，保留可用画布和底部状态；当前音色按钮自动滚入视野 |

常用窗口键：F4 新建 Pattern，F5 编排，F7 来源编辑器，F12 最小化，Ctrl+Shift+H 平铺，Enter 最大化/还原。原生系统窗口中的 Enter/F12 操作当前系统窗口，内部平铺与 Ctrl+Tab 只作用于主工作区。F2 重命名当前来源。

Backspace 现在关闭/恢复原吸附，删除使用 Delete。Ctrl+D 取消选区，Shift+I 反选；Ctrl+上下及原有 Shift+上下均支持八度移调。保留本项目 Ctrl+N 新建、Ctrl+E 导出 NBS 和一次终止归零的约定。

## 验证结果

- TypeScript 严格检查及 noUnusedLocals 通过。
- Vitest：22 个文件、148 项全部通过。实际浏览器组件测试覆盖按键修饰、输入与对话框保护、音色导航、虚化后的画布像素、力度条、选区清晰度、无工程/音频副作用，以及紧凑尺寸。
- 源码构建上的实际 Electron：基础 20、智能导入 12、片段与交互 18、工作区与快捷键 15，共 65 组通过。
- Windows ZIP 实际解压后对解压 EXE 重跑上述 65 组，全部通过，无 renderer 异常。两轮合计 130 组真实桌面流程。
- ZIP 77 项；asar 29 项；22 个构建文件与 out 逐文件一致，运行包不含项目 src、tests、node_modules。
- 查看实际平铺和音色虚化截图；所有操作测试使用真实 IPC、磁盘读写、解码和鼠标/键盘，只替换系统路径选择。
- 独立代码审查发现的小窗口画布被音色栏挤没问题已修复，失败回归转为通过；复核无新的具体可操作问题。

工作区新增 15 组：独立编排框架；移动/缩放；F5 恢复；F7 与窗口切换；平铺；搜索帮助；输入框保护；原生 Playlist 与来源选择；跨窗口共享编辑与撤销；停靠；F12 恢复；F4 新建撤销后的有效来源；F2 重命名及撤销；暂停状态停靠交接；关闭活动窗口后的焦点恢复。

整合回归另修复：Playlist 标记误命中全局 `.playlist` 样式与焦点选择器；撤销新建 Pattern 后的悬空来源；活动窗口关闭/最小化后焦点仍指向不可见窗口；隐藏浏览器时仍可在编排工具栏选择来源；帮助窗口宽度溢出。

## 保留范围

音色聚焦只影响视觉，不改变播放、导出或数据；选中其他音色音符时保持清晰。停靠播放窗口会转交位置，重新准备音频时可能有短暂间断。独立编辑实例的视图设置各自维护，工作区布局尚未写入工程文件；重开软件使用默认布局。

没有把全部 FL 功能或快捷键套用到 NBS：切片、滑音、效果器、MIDI 智能转换、鼓点素材库、半自动配器仍不在本轮范围。macOS/Linux 未打包验证。

源码与运行目录分开；本地保留最新 0.6.0 运行目录，历史源码归档和验收记录保留。GitHub 备份按仓库管理规则更新。
