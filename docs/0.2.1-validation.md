# 0.2.1 滚动黑屏修复

用户在 0.2.0 中拖动 Playlist 底部横向滚动条后，整个窗口内容消失。

根因是 Playlist 的 onScroll 回调在 React 状态更新函数内读取事件 currentTarget。React 在事件处理结束后清空 currentTarget，后续状态更新读取 scrollLeft 时抛出异常，使根组件卸载。现在在事件处理期间同步提取两个数值，状态更新只使用数值。

回归脚本 `scripts/scroll-regression.cjs` 用真实鼠标拖动原生横向滚动条，在旧运行包中复现黑屏并捕获 `Cannot read properties of null (reading 'scrollLeft')`。修复后验证拖动、反复横纵滚动、滚动后缩放以及 Pattern 钢琴卷帘滚动。

运行 `pnpm test:scroll` 验证构建目录，`pnpm test:scroll:packaged` 验证运行包。`NBE_PACKAGED_APP` 可以指定 ZIP 解压后的 EXE。另运行原有 57 项单元测试、TypeScript 检查及完整桌面文件读写验收。0.2.0 的功能记录保留在 `docs/0.2.0-validation.md`。

本补丁不修改工程和 NBS 文件格式。源码和运行文件分别打包至 `deliverables/NoteBlockEditor-0.2.1/`，旧版输出保留便于比较。

最终验证：TypeScript 检查、6 个文件的 57 项单元测试通过。0.2.1 Windows ZIP 解压后的 EXE 通过上述滚动回归和原有 10 组桌面验收，渲染错误为零。35,361 音符的文件读写往返、退出后重开验证通过。记录在 `test-results/scroll-packaged.json` 和 `test-results/smoke-packaged.json`。
