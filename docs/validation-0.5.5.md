# 0.5.5：重做通透玻璃材质

用户否定了 0.5.4 的视觉结果，并明确要求参考文档中的通透玻璃／水晶质感。此前实现错误地将参考压成不透明灰绿平涂；本次完整移除旧主题，重新构造材质，不把简单恢复旧外观作为最终答复。

使用连续的静态青蓝／深蓝／淡紫光场，窗口背景为低透明度薄层，整窗背景模糊使后方对象形成可见的模糊色彩；一像素白色轮廓和内侧边缘反光形成清晰的玻璃边界。菜单单独模糊其后方内容。没有空闲背景动画或新增运行依赖。

画布此前的不透明灰底会遮蔽材质，此次将 Pattern／Playlist 的底色、交替行、标尺与网格色集中到 renderer/canvasTheme.ts，以深色透光层保持音符对比；Canvas 每次先重置尺寸，半透明绘制不会累计。音符本身的来源颜色、选区、坐标、命中、滚动与编辑逻辑不修改。

纯色开屏、宿主连接重试和过期结果取消继续保留；开屏与原生首帧背景同步为中性暗灰，详细开屏设计仍留待后续。音乐模型、文件格式、音频、编辑交互与窗口功能不修改。随旧主题删除仅覆盖旧装饰呼吸动效的测试，保留全部启动生命周期测试。提供不支持背景模糊／用户偏好降低透明度时的实体底色，以及强制高对比模式的系统边框与焦点。

验收证据在交付目录的 verification 中，包含实际 EXE 回归、开屏检查、截图、包内容匹配及源码完整性检查。只在新包验证后清理 0.5.4 运行目录，历史源码与 Git 标签保留。

最终检查：TypeScript（含 unused locals）通过；37 个测试文件、310 项测试通过（较上一版移除 1 项已删除呼吸动效的专用断言）。真实 0.5.5 EXE 的基础 20 项、和弦／原生编辑器 8 项、开屏 4 项检查全部通过，无未处理 renderer 异常。22 个包内构建文件与当前构建逐项哈希一致，附带说明一致。

已核对整曲、重叠窗口、菜单、和弦面板、独立窄窗口及 35,000 音符场景截图；自查确认改动仅为显示材质和底色，未改动编辑命中或音乐状态。历史 0.5.4 源码 SHA256 核对后保留，其运行目录已清理，当前只保留 0.5.5 运行版。最终源码提交、归档校验与远端备份在 verification/summary.json 中记录。
