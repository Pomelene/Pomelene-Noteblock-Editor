# Pomelene 和弦实验室 · Demo 01

独立交互试验，先调试几轮，再决定如何接入正式编辑器。没有新建完整应用，没有修改正式工程模型或正式编辑器的和弦功能。

直接双击 `index.html` 用桌面浏览器打开即可使用。脚本、样式和 Harp／Pling 音符盒采样都在此目录中，不依赖网络或 Node.js。音频首次播放需用户点击；已有编辑器采样沿用原许可，见 `OpenNBS-LICENSE.txt`。

## 本轮交互

1. 点击上方小节／拍刻度或网格，选择插入 tick。四小节，4/4，每拍 4 tick。
2. 点击下方和弦卡片，立即生成并放置一组音符，同时试听。调性支持大调和自然小调。
3. 右侧选择自定义根音、音区、和弦类型、转位、附加音、低音与开放排列；“放置”写入，“试听”不写入。
4. 齐奏同时触发；分解方式逐音相隔 1 tick。末尾装不下时整次拒绝，不丢弃部分和弦音。
5. 同一落点可替换原和弦或叠加；可选放置后前进一拍、两拍或一小节。
6. 撤销／重做一次处理整组；右键可删除单个音符；清空可以撤销。本机暂存恢复的是已放置音符和插入点，不是正式工程。
7. 空白处左右键盘方向键移动插入点；数字 1–7 放置对应条带；Ctrl+Z／Y 撤销／重做；Esc 停止声音。输入控件保留正常文字及数值操作。

Harp／Pling 采用项目现有音符盒录音，按 MIDI 66 为采样基准进行调音。放置的是一次触发的音符，不伪造 NBS 没有的持续音符时值。

“导出音符 JSON”仅用于保存试验结果和后续对接讨论，格式为 `pomelene-chord-lab` version 1，不是 `.nbproject` v2，也不声称可直接作为 `.nbs` 导入。本 demo 不读写当前正式工程。

## 参考与自行决定的部分

- [Apple：添加自定义和弦](https://support.apple.com/zh-cn/guide/garageband-ipad/chsab9d1c4c/ipados)：根音、和弦质量、附加音与备用低音。
- [Apple：使用和弦条带弹奏键盘](https://support.apple.com/zh-cn/guide/garageband-ipad/chs39282dbe/ipados)：把常用和弦组织为可直接触发的条带，另有低音和伴奏样式。
- 本项目自行设计了“选时间落点后写入 NBS 音符”、原子撤销、碰撞策略、四小节测试区和开放排列；不将这些说成 GarageBand 的原样行为。

算法、数据和 UI 放在独立文件，之后可以迁移经验证的纯音符生成逻辑；正式对接前仍需适配当前图层、音色编号、命令事务与工程 generation 校验。

## 验证

在仓库根目录运行：

```powershell
node --test demos/chord-lab/engine.test.cjs
node demos/chord-lab/smoke.cjs
```

覆盖和弦音程、调内和弦、转位／开放排列／低音、生成时间、范围拒绝，以及真实浏览器的放置／撤销／导出／音频／本机恢复。浏览器结果与截图位于忽略的 `test-results/chord-lab`。
