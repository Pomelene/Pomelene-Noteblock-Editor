Pomelene Noteblock Editor 0.5.3 — 简约界面

解压整个 Windows ZIP 后运行“Pomelene Noteblock Editor.exe”。请保留同目录 resources 等文件。
不需要安装 Node.js。源码另放在独立 source ZIP 中。

快速操作
1. 启动时显示可试听的示例工程；“文件 → 新建工程”创建空白工程。
2. “文件 → 打开”可打开 .nbproject 工程和 .nbs 歌曲。
3. 左侧 Pattern 为可编辑乐段；“采样”为只读音符片段。单击选择，双击打开编辑或只读预览，可重复打开同一源。
4. 将对象拖到 Playlist，或选择对象后左键点击轨道放置引用。
5. 拖动引用移动；拖动左右边缘调整长度。拖长补空白，缩短裁播放窗口，源数据保留。
6. 右键点击编辑画布上的音符或引用直接删除。对象列表和轨道头右键打开菜单。
7. 窗口标题栏可移动、双击最大化；支持四边/四角缩放、还原、最小化、独立桌面弹出。
8. Pattern 内可切换钢琴卷帘与 NBS 图层。音色选择、落笔图层和音符属性均在编辑窗口。
9. Ctrl 拖动框选；Shift 拖动复制；Alt 临时使用更细网格。方向键移动选区。
10. Ctrl+C / X / V 复制、剪切、粘贴；Ctrl+B 向右接续复制；Delete 删除；Ctrl+Z / Y 撤销重做。

快捷键与窗口组合
F1 打开可搜索的完整快捷键表；文件和播放操作为全局，音符/引用操作只作用于当前获得焦点的编辑器。
F4 新建 Pattern；F5 显示整曲 Playlist；F7 打开或恢复当前来源的编辑器；双击浏览器对象仍可新增多个实例。
Ctrl+Tab / Ctrl+Shift+Tab 前后切换当前工作区的可见窗口；Ctrl+Shift+H 平铺，窗口菜单也提供层叠排列。
Enter 最大化/还原当前子窗口；F12 最小化所有内部窗口，F5/F7 或底部窗口栏恢复。独立桌面窗口中 Enter/F12 操作该系统窗口。
整曲 Playlist 有自己的标题栏，可拖动、八方向调整尺寸、最大化/还原、最小化/关闭；切回编排不会最小化其他窗口。
标题栏“弹出桌面窗口”打开独立系统窗口，可自由跨屏摆放；独立窗口顶部“停靠”返回主工作区。
独立 Playlist 使用顶部“放置来源”选择 Pattern、只读片段或音频；所有窗口共享工程修改和撤销历史。
停靠持有播放的窗口时会转交播放状态与位置，音频设备重新准备期间可能短暂间断。
Ctrl+A 全选、Ctrl+D 取消选择、Shift+I 反选；方向键按网格移动，Pattern 的 Ctrl+上下或 Shift+上下升降八度。
Home 定位起点，End 定位内容末尾；PageUp/PageDown 缩放；Shift+1/2/3 缩放预设，Shift+4 适应全部，Shift+5 适应选区。
Backspace 关闭/恢复原吸附；删除使用 Delete。Alt 临时自由定位。
输入框中方向键、删除、剪贴板、撤销按文字编辑处理；Ctrl+S 等文件操作仍可使用。对话框开启时不触发后台编辑。
按钮获得焦点时 Enter/Space 仍然激活按钮；画布获得焦点时 Enter 控制窗口、Space 播放/暂停。

Pattern 音色聚焦
音色区显示当前落笔音色及音符数量，点击下方音色按钮切换；G/K 前后切换所有音色，H/J 前后切换本 Pattern 用到的音色。
音色按钮也支持方向键选择；“显示全部音色”取消虚化。选中音符保持清晰，便于批量操作。
其他音色的音符与力度条以 22% 不透明度显示，仅改变视觉；播放、导出和乐器资源不变，仍可选中其他音色音符。

连续操作与吸附
P 绘制：单次放置，按住拖动可先调整新对象位置再松开提交。
B 笔刷：左键按住拖动连续放置。编排按源片段长度接续；钢琴卷帘按吸附格连续放置音符。
快速扫过的格子会补齐，回扫不会重复添加；一个手势一次撤销。
右键按住拖动连续擦除；D 为左键删除工具，E 为框选工具。
Ctrl 临时框选；空白处 Shift 临时笔刷；已有对象上 Shift 拖动复制。
Esc、窗口失焦、失去指针或切换工程会取消尚未提交的手势；超出 10,000 个位置的笔刷手势会取消并提示。
编排 T 静音点击的引用，S 滑移引用的源内容，保留引用位置与长度；这些操作均可撤销。
片段边缘会显示横向调整光标，拖动时显示长度与补白。短片段也可以拖尾；只改这一条引用。
吸附选择器用拍值显示，1 拍为四分音符（4 tick），1/4 拍为十六分音符（1 tick）。
三连音中 1/3 拍为 4/3 tick；1 小节随拍号变化。自动网格随水平缩放改变。
关闭吸附或按住 Alt 可自由定位到内部精度；改变吸附不会量化现有音符。
拖动按相对位移吸附，保留已有离格偏移。小数 tick 导出 NBS 时仍需取整，并会提示。

只读片段采样
Pattern 对象列表右键 → 保存为片段采样，创建独立快照。
编排左上角的小角标菜单 → 保存选区为片段采样，可保存多个已选音符片段的可见窗口，包含中间空白和末尾补白。
含音频引用的选区不能转换为音符采样，会明确提示。
文件 → 导入 NBS 片段采样，可加入当前片段库，不替换工程；自定义乐器和可找到的音频会一起关联。
外部片段保留原始 tick，跟随当前工程 BPM；原速度不同会提示。
双击片段打开只读预览，可查看音符、缩放、预听；不能直接添加、删除或修改音符和图层。
根据采样创建 Pattern 后再编辑，使用独立的对象/音符/图层 ID，不影响原采样。
编排中采样引用的小角标菜单也能创建 Pattern，仅替换这一个引用。
片段采样可重命名、改色、删除、重复引用；尾部拉长补静音、缩短截断播放，源内容保持只读。
采样的乐器定义仍属于当前工程；“只读”冻结的是音符与图层快照，不是额外渲染的声音文件。
旧版音频和单音乐器素材仍在折叠的“音频 / 乐器资源”区域，也可用“音频”页签查看。

播放
SONG 播放编排；PAT / SMP 播放所选对象。空格播放/暂停，暂停保留位置。
方形“终止”按钮一次回到开头，同时将播放竖线和水平视图带回左侧。
顶部可直接设置 BPM、拍号与循环开关。BPM 输入后按 Enter 或移开焦点生效。
打开新的编辑实例不会叠加播放或打断当前播放；关闭持有播放的桌面窗口会停止并释放状态。

保存与交换
Ctrl+S 保存完整 .nbproject，包含 Pattern、采样、引用、图层和内嵌音频。
首次保存会询问位置；Ctrl+Shift+S 另存。导入 NBS 后保存工程使用新的工程文件。
Ctrl+E 导出 NBS v5。读取支持 NBS v0–v6；导出仍为 v5。v6 铜号保留为具名自定义资源，需要对应音频。
内部细分网格可含小数 tick；NBS 仅支持整数 tick，导出时会提示取整。
原始音频采样引用无法成为 NBS 音符，导出会提示省略；工程文件保留完整内容。
音频资源预听的基准/音量/声像仅在工程中生效，NBS 使用音符/图层/自定义乐器调音数据。
只读片段采样本身是音符数据，可以正常导出 NBS；完整 .nbproject 会保留片段库和只读分类。
新版本可读旧工程；含片段采样的新工程需要 0.5 或更新版本。

自定义乐器
可打开带自定义乐器的 NBS，或“文件 → 导入 NBS 乐器 / ZIP”。
定义从 NBS 读取；音频 ZIP 按相对路径自动关联，无需逐个重选。工程保存后音频随工程携带。
“文件 → 导出乐器采样包”将当前自定义乐器音频打包为保留相对路径的 ZIP，与对应 NBS 一同使用。
不含定义的音频 ZIP 会保留为音频资源，不能凭空推断 NBS 乐器定义或转换成音符片段。

智能 Pattern 整理（Beta）
打开 .nbs 后先显示导入预览，勾选“智能 Pattern 整理（Beta）”再导入。
可取消勾选，继续使用原始单 Pattern；取消或 Esc 不替换当前工程。
预览显示原始音符、图层、拍号、整理前后数量、分组和提示。
算法结合图层名称、同拍发声关系、音域、乐器与小节特征，按声部拆出可编辑对象。
会尝试 1、2、3、4、6、8 小节乐句；只有音符、表现参数、图层设置和长度完全相同才共用 Pattern。
不会量化、移调、删掉重复击打，或把相似变奏强行合并。SONG 中保留原始尾音跨越新乐句边界。
手动裁剪引用会采用普通裁剪语义；Pattern 单独试听按它自己的长度播放。
“帮助 → 智能整理报告…”查看本次分组和算法版本。
“编辑 → 恢复原始导入布局…”会替换当前音符和编排，请先保存要保留的编辑。恢复后可 Ctrl+Z 撤销。
保存 .nbproject 会保留整理结果、报告及原始布局备份，重开工程不会再次分析。
.nbs 不含 Pattern 结构；导出后的音符仍是普通 NBS，重新导入时可以再次整理。
超出分析或输出预算时使用原始布局，并给出提示。
Beta 还可能过度拆分，也不能可靠判断主歌/副歌、所有跨小节乐句或同音色交织声部。

当前范围
本版交付重建后的桌面编辑核心。MIDI 智能转换、鼓点素材库、半自动配器与丰富听感尚未实现。
和弦工具已提供基础三和弦/七和弦快捷放置；不包含效果器、切片和滑音。
平台适配目前验证 Windows x64；macOS/Linux 尚未打包验证。

兼容处理与播放目标
旧 NBS 的已知零填充可自动识别；少报图层按真实音符位置补全；未声明的经典扩展原版音色按已知ID读取。所有修复均在导入预览提示。
异常力度如125会明确提示规范为100；未知非零尾部、损坏的音符段及未知版本仍拒绝，保护当前工程。
单 Pattern 支持最多500,000音符，工程总数最多1,000,000，NBS输入仍有32MiB保护。
点击编排内的来源引用、激活Pattern编辑窗口或底部窗口栏都会更新PAT目标；PAT正在播放时切换到该来源，SONG继续整曲播放。
位置显示TICK保持三位，单位仍是拍内tick乘100。

主要编辑操作
- 编排右侧“行高”可设 24–128；Pattern 的 NBS 图层可设 20–96，钢琴行高可设 12–48。按 Enter 或离开输入框确认；超出范围时会归入有效范围。
- 鼠标置于编辑画布，按 Ctrl+滚轮缩放时间尺度，鼠标处时间尽量保持原位置；普通滚轮滚动。
- 添加菜单 → 自定义音色与映射，或展开“音频 / 乐器资源”点击音符图标。手选播放／导出目标，试听后可保留；建议需点击“应用建议”才生效。也可在资源设置中的自定义乐器处修改。
- 绑定不改写源音符和原采样引用，可重置、撤销，保存工程后仍可修改。NBS 导出会应用替换并补偿原音色调音；NBS 本身不保存可再次编辑的绑定，请同时保留 .nbproject。
- 整理预算与工程对齐。复杂歌曲会使用共享轨道或较长乐句，报告提示采用的策略；原图层与所有音符仍保留。最大测试歌曲 265,495 音符，初次整理约 11 秒。

工程 v2 与 NBS 控制事件
.nbproject 现在使用带 PNE-PROJECT v2 前缀、长度与 CRC32 校验的新格式，旧 JSON 工程不再导入。
NBS 变速器和停止发声事件参与整曲播放；视觉事件可在音频 / 乐器资源的控制事件列表查看，目前只保留、不执行视觉效果。Show Save Popup 不会保存文件。
带全局控制事件的 NBS 请使用“文件 → 打开”，不要作为单个片段采样导入。

和弦生成器
在 Pattern 工具栏点击“和弦生成器”，右侧属性栏切换为和弦面板。
面板打开时，网格左键选择时间；钢琴卷帘同时选择根音，NBS 图层视图选择起始图层，不会额外画单音。
选择调内和弦卡片，或调整根音 MIDI、和弦类型，再点击“放置和弦”。试听使用当前落笔音色及力度。
“转位与排列”可调整附加音、转位、低音与开放排列；支持同时触发及上下行分解、放置后前进。
默认追加，自动跳过锁定和已占用图层；勾选替换时，仅替换生成时刻的当前音色，保留锁定音符和其他音色。
一次放置可用 Ctrl+Z 撤销整组。生成的都是普通工程音符，关闭面板后仍可自由编辑。
按住右键拖动，擦除沿途碰到的音符；快速移动仍检测经过的音符，锁定图层不删。松开一次提交，Ctrl+Z 一次恢复；Escape 或窗口失焦取消整次预览。
工程仍使用 v2 格式，NBS 输入输出格式不变。

界面简化（0.5.3）
顶部“整曲”播放整个编排；“当前片段”播放当前选中的 Pattern 或采样。
速度、拍号、播放位置保留在顶部。音色名称、数量与选择状态位于 Pattern 编辑窗口。
常驻说明已精简；F1 或“帮助 → 操作与快捷键”查看完整操作，和弦面板底部“使用说明”查看放置与替换规则。
