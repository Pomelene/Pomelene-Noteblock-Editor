NoteBlock Editor 0.3.0 — 桌面重构版

解压整个 Windows ZIP 后运行“NoteBlock Editor.exe”。请保留同目录 resources 等文件。
不需要安装 Node.js。源码另放在独立 source ZIP 中。

快速操作
1. 启动时显示可试听的示例工程；“文件 → 新建工程”创建空白工程。
2. “文件 → 打开”可打开 .nbproject 工程和 .nbs 歌曲。
3. 左侧 Pattern 与采样均为源对象。单击选择，双击新增编辑实例；可反复打开同一源。
4. 将对象拖到 Playlist，或选择对象后左键点击轨道放置引用。
5. 拖动引用移动；拖动左右边缘调整长度。拖长补空白，缩短裁播放窗口，源数据保留。
6. 右键点击编辑画布上的音符或引用直接删除。对象列表和轨道头右键打开菜单。
7. 窗口标题栏可移动、双击最大化；支持四边/四角缩放、还原、最小化、独立桌面弹出。
8. Pattern 内可切换钢琴卷帘与 NBS 图层。音色选择、落笔图层和音符属性均在编辑窗口。
9. Ctrl 拖动框选；Shift 拖动复制；Alt 临时使用更细网格。方向键移动选区。
10. Ctrl+C / X / V 复制、剪切、粘贴；Ctrl+B 向右接续复制；Delete 删除；Ctrl+Z / Y 撤销重做。

播放
SONG 播放编排；PAT / SMP 播放所选对象。空格播放/暂停，暂停保留位置。
方形“终止”按钮一次回到开头，同时将播放竖线和水平视图带回左侧。
顶部可直接设置 BPM、拍号与循环开关。BPM 输入后按 Enter 或移开焦点生效。
打开新的编辑实例不会叠加播放或打断当前播放；关闭持有播放的桌面窗口会停止并释放状态。

保存与交换
Ctrl+S 保存完整 .nbproject，包含 Pattern、采样、引用、图层和内嵌音频。
首次保存会询问位置；Ctrl+Shift+S 另存。导入 NBS 后保存工程使用新的工程文件。
Ctrl+E 导出 NBS v5。读取支持 NBS v0–v5；v6 目前明确拒绝。
内部细分网格可含小数 tick；NBS 仅支持整数 tick，导出时会提示取整。
原始音频采样引用无法成为 NBS 音符，导出会提示省略；工程文件保留完整内容。
采样预听的基准/音量/声像仅在工程中生效，NBS 使用音符/图层/自定义乐器调音数据。

自定义乐器
可打开带自定义乐器的 NBS，或“文件 → 导入 NBS 乐器 / ZIP”。
定义从 NBS 读取；音频 ZIP 按相对路径自动关联，无需逐个重选。工程保存后音频随工程携带。
“文件 → 导出乐器采样包”将当前自定义乐器音频打包为保留相对路径的 ZIP，与对应 NBS 一同使用。
不含定义的音频 ZIP 会保留为采样对象，不能凭空推断 NBS 乐器定义。

当前范围
本版交付重建后的桌面编辑核心。MIDI 智能转换、鼓点素材库、半自动配器与丰富听感尚未实现。
和弦工具已提供基础三和弦/七和弦快捷放置；不包含效果器、切片和滑音。
平台适配目前验证 Windows x64；macOS/Linux 尚未打包验证。
